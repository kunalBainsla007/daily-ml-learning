## 📌 About This Repository

This repository tracks my daily journey of learning **Machine Learning**, **Mathematics**, **Deep Learning**, **NLP**, **Computer Vision**, and **LLMs/Generative AI**.

⚡ **Fully Automated Mobile Logging**: Every time I log my daily learnings via GitHub Issues (from phone or browser), a **GitHub Action** automatically:
1. Generates structured Markdown notes in [`logs/`](logs/).
2. Updates current learning streaks & total logged count.
3. Automatically updates the **Progress Table** below.
4. Commits and closes the issue seamlessly!

---

## 📱 How to Log From Phone (In 30 Seconds)

```
1️⃣ Open GitHub Mobile App (or web browser)
2️⃣ Tap "Issues" ➡️ "New Issue" ➡️ Select "📝 Daily ML Learning Log"
3️⃣ Fill the quick form & tap "Submit"!
🚀 GitHub Action takes care of git push, streaks & formatting automatically!
```
