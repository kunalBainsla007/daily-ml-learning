1. Gradient Descent
   - Learned the concept and working of Gradient Descent.
   - Used to minimize the cost/loss function.
   - Learned how weights and parameters are updated step by step.
   - Learned the importance of the learning rate.

2. Types of Gradient Descent

   a) Batch Gradient Descent
   - Uses the complete dataset to calculate the gradient.
   - Stable updates but can be slower for large datasets.

   b) Stochastic Gradient Descent (SGD)
   - Uses one data point at a time to update the parameters.
   - Faster updates but can be noisy.

   c) Mini-Batch Gradient Descent
   - Uses a small batch of data points for each update.
   - Combines advantages of Batch and Stochastic Gradient Descent.
   - Commonly used for efficient model training.

3. Polynomial Regression
   - Learned Polynomial Regression.
   - Used when the relationship between input and target is non-linear.
   - Extends Linear Regression by adding polynomial features.
   - Example:
     y = b0 + b1x + b2x² + b3x³ + ...

4. Bias and Variance
   - Learned the concepts of Bias and Variance in Machine Learning.

   Bias:
   - Error caused by an overly simple model.
   - High bias can lead to underfitting.

   Variance:
   - Error caused by a model being too sensitive to the training data.
   - High variance can lead to overfitting.

5. Bias-Variance Tradeoff
   - Learned the balance between Bias and Variance.
   - Goal is to build a model that generalizes well to unseen data.
   - High Bias → Underfitting
   - High Variance → Overfitting
